How the match is determined
For every row, the tool builds a small set of identifying tags from the Subject side (last path segment of the Subject, plus the Property tag when it's written as PointName.Value) and from the Target side (last path segment of the Target, plus the Target Property when it isn't a generic name like Value/Status).
A row passes (green) if any Subject tag and any Target tag are equal, or one contains the other — e.g. EU045041_PDT_03_Log and EU045041_PDT_03 share EU045041_PDT_03. If no tag pair lines up, the row is flagged (yellow) for manual review. Generic navigation/link properties and shared function-block references (e.g. a common Trend Enable or PID_Fct source) will often flag yellow even when correct — that's expected, just glance and confirm.
